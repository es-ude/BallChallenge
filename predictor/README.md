# BallChallenge

## Installation Instructions

### Download the source code

```bash
git clone https://github.com/es-ude/BallChallenge.git ballchallenge
cd ballchallenge
```

### Get Data

The data can be requested from [David P. Federl](mailto:david-peter.federl@uni-due.de)
Copy/Move the Data to the ./data folder

### Setup Python Environment

1. Install [astral-uv](https://docs.astral.sh/uv/getting-started/installation/)
2. Run `uv venv .venv` to create a virtual python environment
3. Run `uv sync --all-groups` to install all required dependencies
4. Run `source .venv/bin/activate` to activate the virtual environment
